# 市场情报驾驶舱

固定入口：https://underbobo.github.io/market-intelligence-console/

登录页和驾驶舱前端直接托管于 GitHub Pages，使用期间地址栏保持此站点地址。后台 API 经独立认证的 HTTPS 通道连接采集主机，所有数据操作和下载均需有效登录。

本仓库仅包含可公开的前端资源，不包含网站密码、平台账号、后端配置、浏览器登录态、任务数据库或已采集文件。完整源码另存于管理员的私有仓库。

跨域请求使用有期限且可撤销的会话令牌，不依赖第三方 Cookie；退出后令牌在服务端失效。网址中不携带密码或会话令牌。

本机开机看护自动恢复服务与公网通道，通道地址变化时自动更新页面中的后台连接配置。采集主机仍需保持开机联网。
